# First Person Shooter (Brave Engine template)

A first-person shooter to start from, for the Brave Hub's **New Project from Template**: a playable level, a first-person character (Bravo or Brava) with a rifle that is carried relaxed or alert, interaction with E (doors that turn or slide, a drawer, pickups, a socket), cube enemies in waves, a HUD, and placeholder sounds. It is a whole game project: open it in the Brave Editor and press **Ctrl+P**.

**Controls:** WASD move, Shift run, Ctrl crouch, Space jump, mouse look, left mouse fire, R reload, E use, 1 weapon away.

**Read next:** `docs/template.md` (what is where, how the parts talk, how to make it yours) and `AGENTS.md` (the engine, for you or for an AI assistant).

**Credits and licences:** `NOTICE.md`. No Mixamo files are shipped; keep your own in `mixamo/` (ignored by git).

This folder is one entry of the catalog in the repository root (`catalog.json`, `fps/template.json`); the Hub downloads the whole repository's archive and takes this folder.
